# Play with May — support and privacy

The two pages App Store Connect requires, and nothing else.

- [Privacy policy](https://minchangyi.github.io/play-with-may/privacy.html)
- [Support](https://minchangyi.github.io/play-with-may/)

The app's own source lives in a private repository. This repo is public
only because these two pages have to be reachable by anyone, including an
App Review reviewer. The master copies are the app repo's `docs/`; edit
there and copy across, or the two will disagree.
